Para respeitar os serviços gratuitos, o sistema consulta um destino por vez. Recomendado: até 20 CEPs por lote.

Como o cálculo funciona

  • O CEP é consultado no ViaCEP para obter o endereço.
  • O endereço é geocodificado no OpenStreetMap/Nominatim.
  • O OSRM calcula a rota rodoviária entre os pontos encontrados.

A distância é uma estimativa baseada no ponto geográfico localizado para o endereço do CEP; não representa necessariamente o portão exato do imóvel ou o percurso de um caminhão. Restrições de circulação, pedágios, tipo de veículo, trânsito e condições das vias não são considerados.

Este protótipo usa serviços públicos gratuitos, sem garantia de disponibilidade. Consulte os termos de uso antes de uso comercial intenso. As consultas são sequenciais e com intervalo para reduzir a carga nos serviços.

Ferramenta independente • Dados de endereço: ViaCEP • Mapas e rotas: OpenStreetMap / OSRM
